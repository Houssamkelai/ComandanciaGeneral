# Comandancia General de Larache – Modèle 3D

Projet de reconstruction 3D de l’ancienne Comandancia General de Larache, au Maroc.

L’objectif est de créer dans Blender un modèle 3D détaillé et aussi fidèle que possible au bâtiment historique, à partir de photographies anciennes et contemporaines, de documents d’archives et de références architecturales.

## Objectifs

- Reconstituer l’architecture extérieure du bâtiment
- Respecter les proportions, façades, ouvertures et éléments décoratifs
- Créer des matériaux et textures réalistes
- Produire un modèle Blender de haute qualité
- Préparer une version optimisée pour le Web au format GLB/GLTF
- Permettre ultérieurement une visite interactive 3D du bâtiment
- Intégrer le modèle au projet « Historia de Larache en fotos »

## Outils utilisés

- Blender
- Codex / ChatGPT
- GitHub
- GLB / GLTF
- HTML / JavaScript pour la future visualisation interactive

## Sources

Le modèle est développé à partir de photographies historiques et actuelles de la Comandancia General de Larache ainsi que de documents permettant d’étudier son architecture.
